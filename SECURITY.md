# Security Policy / セキュリティポリシー

## 脆弱性の報告

脆弱性を見つけた場合は、公開の Issue ではなく、GitHub の [Private vulnerability reporting](https://github.com/atzzCokeK/kintai-plus-mcp/security/advisories/new) から報告してください。

報告には、再現手順・影響する版・想定される影響を含めてください。**API トークンや実在の勤怠データは含めないでください。**

このプロジェクトは個人が運営する非公式の OSS です。対応はベストエフォートになります。

## Reporting a vulnerability

Please report vulnerabilities through GitHub's [private vulnerability reporting](https://github.com/atzzCokeK/kintai-plus-mcp/security/advisories/new), not public issues. Do not include API tokens or real attendance data. This is an unofficial, individually maintained project; responses are best effort.

## 対象の版 / Supported versions

最新の版のみ / Only the latest release.
