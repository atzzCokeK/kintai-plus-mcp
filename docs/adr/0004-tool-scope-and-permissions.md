# 0004. 権限に応じてツールを出し分け、人事マスタの書き込みは扱わない

- 日付: 2026-10-27
- 状態: 採用

## 背景

- 公開 API はトークンの持ち主の権限（企業管理者／一般管理者／従業員）で動く。
- 使えないツールが並ぶと AI が無駄に呼んでエラーになり、選択精度も落ちる。
- 従業員の登録・削除、権限付与、異動などは誤操作時の影響が大きい。

## 決定

- 起動時に権限を確認し、一般の従業員には管理者向けツールを見せない。
- v1 は参照系と、本人の打刻・工数の書き込みのみ。人事マスタの書き込みは扱わない。

## 結果

- 人事マスタ系の要望が出たら、v2 以降で安全策とあわせて検討する。
