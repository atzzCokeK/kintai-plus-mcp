# 0007. 有効期限がわからないトークンは、最初に使うときに再発行して期限を確定する

- 日付: 2026-10-27
- 状態: 採用（ユーザー未確認。見直す場合は相談）

## 背景

- 自動更新（ADR 0003）は「有効期限の残り」で判断するが、ユーザーが貼り付けたトークンや環境変数から取り込んだトークンは、いつ発行されたかわからない。
- トークン単体から期限を知る API は見当たらない。再発行 API の応答には新しいトークンの `expired_at` が含まれる。
- 「今発行されたもの」とみなすと、実際には発行から時間が経っていた場合に、更新前に失効してしまう。

## 決定

- 有効期限が不明なトークンは、最初の利用時に再発行 API を呼び、新しいトークンと期限を保存する。
- 再発行に失敗した場合（通信エラーなど）は、今のトークンをそのまま使い、5 分あけて再試行する。認証エラーなら失効とみなし、マイページでの再発行と `login` を案内する。
- `KINTAI_PLUS_AUTO_REFRESH=false` で自動更新ごと止められる。

## 結果

- 貼り付けたトークンは、最初の利用時に新しいトークンへ置き換わる。同じトークンを他のツールでも使っている場合、旧トークンが失効するかは未確認（api-notes 参照）。README に「このツール専用のトークンを使う」よう書く。
