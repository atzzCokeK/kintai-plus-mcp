# 0008. 実働は開始〜終了の経過で見積もり、休憩は不明とする

- 日付: 2026-10-29
- 状態: 採用

## 背景

- ADR 0006 は、勤務実績 API が実働時間（分）と休憩を返す前提で、法定時間外の目安を計算していた。
- 2026-10-29 の実環境（`atnd.ak4.jp`）では、各レコードにあるのは date、working_day_category、start_time、end_time、rounded_*、attendance_punch_time、leaving_punch_time だけだった。`actual_working_hours_no_rounding` と `break_time_results` は無い。時刻は `yyyy/mm/dd HH:MM:SS` で、終了が翌日以降になる夜勤がある。

## 決定

- 実働の項目が無いときは、開始〜終了（どちらも無ければ rounded_*）の経過分を実働の目安にする。終了が開始より前なら見積もらない。
- この値は休憩を含む。休憩分は 0 とせず「不明」と返す。集計と残業リスクの注意書きにも、経過時間であることと休憩が不明であることを添える。
- API が実働や休憩を返した応答は、これまでどおりその値を使う。

## 結果

- 集計と残業リスクが、実働不明のために 0 になることはなくなる。目安は休憩の分だけ多く出るので、正式な値は勤怠Plus の画面で確認する、という既存の注意は残す。
