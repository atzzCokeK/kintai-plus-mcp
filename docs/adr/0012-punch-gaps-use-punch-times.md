# 0012. 打刻漏れは打刻時刻で判断し、休憩打刻が無いだけでは不足にしない

- 日付: 2026-11-03
- 状態: 採用

## 背景

- ADR 0011 は、勤務実績に開始と終了がある日を打刻漏れにしない、としていた。
- 実環境では、打刻が無くても `start_time` / `end_time` が入る（システム補完や別日の退勤）。その日を閉じた扱いにすると、`team_close_out` が退勤漏れを 0 件にし、同じ日の `get_team_stamps` は `missing_clock_out` になる。
- 休憩不足は打刻の拘束時間を実働として計算していた。実績の実働はすでに休憩を引いていることがあり、ほぼ毎日がエラーになった。

## 決定

- 打刻漏れは、打刻と勤務実績の出勤・退勤打刻時刻（`clockInAt` / `clockOutAt`）で判断する。`startTime` / `endTime` だけでは消さない。
- 退勤打刻が勤務日の当日でないときは、その日の退勤にしない。例外は、同じ日の出勤打刻から 16 時間以内の翌日だけ（夜勤）。
- 出勤打刻が無く退勤だけがある日は、出勤漏れにする。
- 休憩打刻が無い日は不足と断定しない（情報にとどめる）。打刻または休憩実績の分数が、実働に対する法定休憩より短いときだけエラーにする。実働は実績の実働分を使い、打刻の拘束時間で置き換えない。
- 読み取り専用の `close_out` は、登録されていない `punch` などの書き込みツールを案内しない。
- 未出勤の日の見出しは、休憩戻しや退勤を案内しない。

## 結果

- チームの締めと本人の `close_out` が、打刻の抜けを同じ基準で出す。夜勤の翌朝退勤は漏れにしない。
