# 0001. v1 は公開 API のみに対応し、ブラウザ操作は後回しにする

- 日付: 2026-10-27
- 状態: 採用

## 背景

- 当初は「マネーフォワード クラウド勤怠」を想定していたが、本体には一般に使える公開 API がない。
- 公開 API があるのは OEM 版の「クラウド勤怠Plus（旧 AKASHI）」で、従業員ごとにトークンを発行できる。
- API トークンを発行できない人のために、Web 画面を操作する方法も検討した。ただしログインの扱いや画面変更への追従など課題が多く、提供元の利用規約で認められるかの確認も必要になる。

## 決定

- 対象はクラウド勤怠Plus のみ。v1 は公開 API だけを使う。
- Web 画面を操作するバックエンドは、提供元の利用規約で認められることを確認できた場合に限り、次バージョン以降で検討する。そのために「勤怠の操作」を表すバックエンドのインターフェースだけを先に用意し、各バックエンドが対応機能を申告する形にする。
- ツール名・引数は API の形ではなく勤怠の概念で設計し、裏側が増えても見た目を変えない。

## 結果

- 申請・スケジュールは API にないため v1 では非対応。
- 管理者が「公開API利用可否」を有効にしていない人は使えない。README に有効化手順を載せる。
