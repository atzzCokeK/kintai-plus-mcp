# 0001. v1 は公開 API のみに対応し、ブラウザ操作は後回しにする

- 日付: 2026-10-27
- 状態: 採用

## 背景

- 当初は「マネーフォワード クラウド勤怠」を想定していたが、本体には公開 API がない（全権管理者向けの給与連携用 API KEY のみで、一般公開されていない）。
- 公開 API があるのは OEM 版の「クラウド勤怠Plus（旧 AKASHI）」で、従業員ごとにトークンを発行できる。
- API を発行できない人のためにブラウザ操作も検討したが、ログインの扱い、画面変更への追従、規約の解釈など課題が多い。

## 決定

- 対象はクラウド勤怠Plus のみ。v1 は公開 API だけを使う。
- ブラウザ操作は需要が見込めるため次バージョン以降で実装する。そのために「勤怠の操作」を表すバックエンドのインターフェースだけを先に用意し、各バックエンドが対応機能を申告する形にする。
- ツール名・引数は API の形ではなく勤怠の概念で設計し、裏側が増えても見た目を変えない。

## 結果

- 申請・スケジュールは API にないため v1 では非対応。
- 管理者が「公開API利用可否」を有効にしていない人は使えない。README に有効化手順を載せる。
