# 0006. AI に渡すデータを絞り、残業は「目安」として集計する

- 日付: 2026-10-27
- 状態: 採用

## 背景

- 打刻データには緯度・経度と IP アドレスが含まれる。AI に渡したデータは AI の提供元にも送られる。
- 勤務実績 API には残業時間の項目がなく、実働時間（分）・時刻・休憩・労働区分のみ。
- 12 ヶ月分の生データを AI に渡すと情報量が膨大で、計算ミスも起きやすい。

## 決定

- 緯度・経度・IP は既定で返り値から除く（環境変数で含められる）。従業員情報も必要最小限に絞る。
- `summarize_working_hours` で実働合計・出勤日数・休日出勤日数と「法定時間外の目安」（労働日は 1 日 8 時間超、法定休日は全時間）を返す。週 40 時間、変形労働時間制、フレックスは考慮しない。
- 返り値に「目安であり、正式な値は勤怠Plus や給与計算で確認すること」と必ず添える。
